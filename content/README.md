# Content Source Library

This folder is for information used to maintain the website. It is separate
from `public/assets/`, which contains files delivered directly to visitors.

```text
content/
├── events/        schedules, venue details and registration information
├── legal/         privacy, terms, consent and usage records
├── membership/    benefits, onboarding and member rules
├── partners/      partner details and logo permissions
├── people/        biographies and speaker details
├── programs/      curriculum, outcomes, prices and FAQs
└── testimonials/  approved quotes and consent records
```

Do not store private member lists, passwords, payment exports or confidential
personal data in this GitHub repository.
