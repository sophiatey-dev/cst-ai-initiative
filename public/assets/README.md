# Asset Library

This is the website-ready media library. Files placed here can be referenced
from the site using `/assets/folder/filename.ext`.

## Folder map

| Folder | Put these files here |
|---|---|
| `brand/` | CST logo, Kaku logo, brand marks, approved brand guide |
| `people/` | Sophia Tey, Paul Phong, speakers, hosts and panelists |
| `events/forum-air/` | Forum AIR stage, panel, audience and networking photos |
| `events/community/` | Member activities, workshops, groups and networking |
| `learning/` | Course photography, frameworks and programme visuals |
| `about/` | Ka-Ku origin story and initiative background visuals |
| `video/` | Hero loops, highlights, testimonials and event reels |
| `testimonials/` | Participant portraits used with approved quotes |
| `partners/` | Sponsor and partner logos |
| `social/` | Social preview cards and campaign artwork |

## Recommended web formats

- Photos: JPG or WebP, 1800–2400 px wide, ideally below 2 MB
- Transparent logos: PNG or WebP
- Vector logos: SVG
- Hero video: MP4 (H.264), 1920×1080, 8–20 seconds, muted seamless loop
- Animated hero alternative: WebP preferred; GIF only when necessary
- Social preview: PNG/JPG, 1200×630

## Naming convention

Use lowercase words separated by hyphens:

```text
sophia-tey-initiator.jpg
paul-phong-ai-prompt-thinking.jpg
forum-air-01-panel-discussion.jpg
kaku-community-prompt-jam.jpg
partner-company-name.svg
```

Do not use `final`, `new`, `copy`, dates without context, or camera filenames.

## Rights and consent

Before publishing, confirm:

- photographer or source credit;
- permission to publish identifiable participants;
- speaker approval for portrait and biography;
- partner approval for logo use;
- licence or usage basis for third-party historical photography.
